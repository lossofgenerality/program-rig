Open the turntable viewer. A skinned humanoid on a Mixamo-style armature, saved as a glTF binary for Blender, dropped into a small yard so you can drive it. Click the field, then walk, run and jump.

WASD move Shift run Space jump Drag to turn the camera, scroll to zoom Arrow keys work too
  • Filehumanoid_rigged.glb, glTF 2.0 binary, about 720 KB. Passes the Khronos glTF validator with no errors or warnings.
  • AnimationsIdle (3 s), Walk (1 s), Run (0.66 s) as loops, and Jump (0.95 s) as a one-shot.
  • RigOne smooth mesh (about 10,000 vertices) skinned to 22 bones with Mixamo-style names: Hips, Spine, Spine1, Spine2, Neck, Head, LeftShoulder, LeftArm, LeftForeArm, LeftHand, LeftUpLeg, LeftLeg, LeftFoot, LeftToeBase and the Right side. Bind pose is a T-pose.
  • In BlenderFile › Import › glTF 2.0. It arrives as an Armature with the Body mesh bound to it; each animation is its own action on the armature.
